# Superstore Sales Analysis

A SQL analysis of the Sample Superstore dataset — answering 
serious business questions with a slightly unhinged approach.

## Tools
- PostgreSQL
- DataGrip
- Dataset: Sample Superstore (Kaggle)

## Our queries

Performance
- Which region makes the most money?
- Which region discounts the most but profits the least?

Hall of Shame
- What is our single worst-selling product of all time?
- Which month is cursed?
- Which state do we basically just donate to?

Oddly Specific
- What's the slowest shipment ever recorded? (poor Sean O'Donnell💔)

## Knowledge/Practice
- Aggregate functions (SUM, AVG, COUNT, MIN, MAX)
- GROUP BY, ORDER BY, HAVING
- Arithmetics
- Data formatting (ROUND, CONCAT)
